# デザイン v3（オーナー決定 2026-10-28）

**全体は案C（白石・イラスト主役・明るいカード）、文字は案B（鷹野・和モダン）のテイスト。**
見本: 案C `scratchpad/design_proposals/C_shiraishi/`、案B `scratchpad/design_proposals/B_takano/`。
design_v2.md の決まり（機能は消さない・連動禁止・主ボタンは1画面1つ・押せる高さ48px以上・動きを減らす設定に従う）はそのまま有効。v2 と食い違うところは v3 を優先。

## 1. 全体（案C）
- 料理の絵が主役。今日の献立は主菜の絵を画面幅の約6割で大きく、副菜・汁もの・ご飯は下に丸い小カードで添える。
- 主ボタン（柿色）は1画面に1つ、画面下に固定。高さ56px、角は丸。
- 絵の台の色: 主菜=桃 `--stage`、副菜=若草 `--stage-2`、汁もの/ご飯=卵色 `--stage-3`。
- 影は茶色がかったふんわりした影。カードの角丸は 28 / 20 / 14px の3段。

## 3. 文字（案B）
- `--mincho`: 'Hiragino Mincho ProN','Hiragino Mincho Pro','Yu Mincho','YuMincho','Noto Serif JP','Noto Serif CJK JP','IPAMincho','IPAexMincho',serif
- `--gothic`: 'Hiragino Sans','Hiragino Kaku Gothic ProN','Yu Gothic','YuGothic','Noto Sans JP','Noto Sans CJK JP','IPAPGothic',system-ui,sans-serif
- **明朝は「名前」だけ**: 画面名（今日の献立 28px・字間 .16em）、料理名（詳細 30px・字間 .2em／一覧 16px・字間 0）、欄の見出し（17px・字間 .14em）、手順番号（作り方の大きな番号 64px、一覧 18px）。太さ 600。
- **読む文・ボタン・数字・材料はすべてゴシック**。案Cの丸ゴシックは使わない。
- 手順番号は日本語表示のとき漢数字（一・二・三…）、ほかの言語は算用数字。
- 日本語以外の言語では明朝の代わりにその言語のセリフ体（serif）を使い、字間は 0〜.04em に抑える（アラビア語・タイ語・ヒンディー語は字間 0）。
- 外部フォントは読み込まない（端末の標準のみ）。

## 4. 担当
- 三宅（w8）: `:root` のトークンと共通部品（ボタン3種・カード・チップ・トースト・下の固定バー）を v3 に。
- 各画面の担当（戸川・森本・柊・小野寺・八木・椎名・日向）: 三宅の土台が入ったら、自分の画面の色・文字を v3 に合わせる（レイアウトの作り直しは v2 の成果をそのまま使う）。
- 白石: 絵の台の色と絵の大きさの確認（イラスト部）。
