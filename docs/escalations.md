# オーナーへの確認事項（チームから）
形式: 案 / 理由3つ / 選択肢 / 期限。詳細は各会議資料（scratchpad の meeting/*.md）。

## A. お金・名義（公開前に必須）
1. **無料と有料の線引き**（課金・審査部 推奨 B: フリーミアム、マーケ部 推奨 C: 折衷）
   - 理由: 人質批判を避けやすい／閉じられない購入画面の審査上の扱いが未確認／実装済みで切り替えるだけ（`PLAN.freeTier`）
   - 選択肢: A 現状（お試し後ロック）／B 無料版＋Pro／C 折衷／買い切り・年額の追加
   - 期限: App Store 提出前
2. **運営者名・連絡先・公開日**（privacy / support / 著作権欄 / `SUPPORT_EMAIL`）— 個人か法人か
3. **価格**（現状 月額380円・1か月無料）の見直し要否
4. **社会貢献の形**（収益の一部の寄付、団体との連携、無償提供）— 約束の表現は誇大にならない書き方で

## B. 公開・外部に出ること
5. App Store への提出（Secrets 6つ、Pages 設定、App Store Connect の登録、実機 Sandbox テスト）
6. SNS（Instagram / X / TikTok / YouTube / LINE / note / Pinterest）の開設と投稿の開始時期
7. 広報（プレスリリースの送り先・公開）

## C. 人でしか埋まらないこと（外部専門家・実機）
8. アレルギー関連の監修（管理栄養士・専門医・患者会）と費用
9. 母語話者による訳の確認（どの言語から、誰に）
10. 規約・プライバシー文の法務確認
11. 実機確認（写真の読み取り FridgeVision、通知、読み上げ、RevenueCat Sandbox）

## D. 権利・表示
12. 料理の絵（自作 SVG）の権利表記、App Store Connect の「コンテンツ権利」の回答
13. 医療・栄養に関わる新しい表示を載せるか（出典が確認できたものだけ）
14. 日本料理を17言語に訳すか（いまは英語のみ）
