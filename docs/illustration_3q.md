# 料理イラストの基準「斜め上35度」（イラスト部）

- 絵の方向の最終判断: 江口（リーダー。採用数の累計 江口18・白石17・花森15）
- 基準書・部品集・書き出し・manifest の取りまとめ: 白石

真上から見た平面の絵を、少し斜め上から見た立体のある絵に描き直す。3D にはしない。手で組む SVG のまま、器の形と明暗で奥行きを出す。
部品は `tools/illustrations/draw/kit3q.mjs`、見本は `tools/illustrations/draw/3q/_mihon.mjs`（器ごとに1品）。

## 0. オーナー採用の描き方（2026-10-28。これを基準にそろえる）

オーナーの評価で採用された絵: 肉じゃが＝江口、生姜焼き＝江口、味噌汁＝白石、ご飯＝江口、パエリア＝花森（海老は直す）。
指示は「このテイストのいいところを集めて作る」こと。料理の種類ごとに、次の描き方を使う。

| 料理 | 描き方 | 部品 |
|---|---|---|
| 煮物の鉢（肉じゃがなど） | 江口: 煮物の具は放射状の塗りで、縁は煮汁の飴色（`mix(c, '#b9853f', .45)`）。左上に白い照りの弧と鏡の白い点 | `hachi` `surface` `glossLump` `depthVeil` |
| 平皿の肉とたれ（生姜焼きなど） | 江口: kit の `porkSlice` を縦につぶし、`thick` で厚みを出す。下にたれだまりを置き、照りは弧と右端の白い点 | `plate` `slice3q` `tarePool` `shine` |
| 茶碗のご飯 | 江口: `riceDome` のまま。口の中心＋2 に置き、高さは 44〜46 | `chawan` `riceDome` |
| 汁椀（味噌汁など） | 白石: 朱の椀・焦げ茶の漆の内側・細い金の線（もとは藍）。汁は口より下に置き、豆腐は汁に沈める | `wan` `surface` `cube`（`sink`） |
| 角切り・豆・具の盛り | 花森: 地面の形を立ち上げる角柱、光と影の球、奥から手前へ盛る | `prism` `cube` `rangiri` `pea` `bean` `leaf` `byDepth` |

- 器の中身を描いたら、**必ず `depthVeil` を重ねる**（奥を淡く、手前を濃く）。
- **海老は `prawn3q(p, x, y, s, rot, flip)` だけを使う**（花森が直し、部長が確かめて kit3q に入れた）。丸まった胴を横から見せ、頭・殻の節・尾・脚・ひげで一目で海老と分かる。えびフライ・天丼・エビチリ・パエリアなど、海老を使う料理はすべてこれで描く。

## 1. 守ること

1. **視点は水平から約35度。** 水平な円は縦 `SY = 0.56` 倍の楕円にする。高さ z は画面で `CZ = 0.82` 倍だけ上に上がる。面の座標から画面へは `at(o, u, v, z)` を使う。
   - 平たい器（`plate` `ovalPlate` `slabPlate`）だけは約49度で描き、楕円の縦は `SYF = 0.75` 倍にする（江口が確定。.75 が上限で、それ以外の器は `SY = 0.56` のまま）。0.68 では 96px の塗りが46%にとどまり、0.75 で50%に届くため 0.75 にした。
   - 皿の返り値 `o` には `sy: SYF` が入り、`at(o, …)` は自動でその比を使う。
   - 皿の上の `tarePool` と `shredMound` には、最後の引数で `{ sy: Q.SYF }` を渡す。
2. **光は左上。**
   - 器の外の側面は、左が明るく右が暗い。
   - 内壁はその逆で、左の内壁が陰、右に光が当たる。
   - 具は上の面を明るく、側面を暗くする。
   - 影は右下に落とす。
3. **器には次の5つを必ず描く。**
   - 楕円の口
   - 口の厚み（上面）
   - 側面（高さ）
   - 高台（平らな底の器はなし）
   - 接地の影（`ground`）
4. **中身の高さを分ける。**
   - 汁・煮汁は口より下の面にする（`surface`）。手前は器の口に隠れる。
   - 具は中心ほど高く盛る。手前の口より上だけを見せるには `V.above` で切る。
5. **奥から手前へ描く。** `byDepth([[y, () => svg], ...])` で並べ替えてから描く。
6. **色は今の絵のまま。**
   - 黒は使わない。いちばん暗い色も焦げ茶（`SHADE = #3a2212`）にする。
   - 漆の内側は焦げ茶、鉄・石の鍋は灰か焦げ茶の石にする。
7. **材料どおりに描く。** `index.html` の R(...) 行（各国料理は packs/*.js）の ings と seas にないものは描かない。
   - 「?」の付いた材料（お好みで）は描いてもよい。
   - 飾りの葉、ミニトマト、レモンなども、材料になければ描かない。
8. **外の素材・フォントは使わない。** SVG を手で組む。

## 2. 縁の色（2026-10-28 オーナーの決定 4番「器の藍の縁をなくし、青のない色にそろえる」）

器の縁・帯・点に**藍・青は使わない**。kit3q の器は、器の雰囲気に合う次の色を初期値に持つ（`Q.RIM`）。

| 器 | 色 | 線 | 部品 |
|---|---|---|---|
| 平皿・楕円皿 | 錆 `RIM.sabi` #9a5f34 | 口の内側に線（2〜2.2） | `plate` `ovalPlate` |
| 長皿・角皿 | こげ茶 `RIM.koge` #5a3826 | 口の内側に角丸の線（2） | `slabPlate` |
| 茶碗 | こげ茶（鉄絵）`RIM.koge` | 口の線と胴に帯2本 | `chawan` |
| どんぶり | 柿（赤絵）`RIM.kaki` #bf5a2c | 口の線と点、胴に帯1本 | `donburi` |
| 白い鉢（中華碗・粥碗） | 灰 `RIM.hai` #8a8076 | 口の線（粥碗は帯も） | `shiroBowl` |
| 煮物の深鉢 | 柿 `RIM.kaki` | 口の線（2.2） | `hachi` |
| 漆の汁椀・土鍋 | 金 `RIM.kin` #c49a42 | 口に細い線1本（1.2） | `wan` `donabe` |
| 鋼の鍋・石鍋 | 灰 `RIM.hai` | 口に細い線1本（1.2） | `pan` `donabe({ stone: true })` |
| ガラスの鉢（そうめん） | 若草 `RIM.wakakusa` #7d9a46 | 細い線。ガラスは淡い若草色 | `vessel` |
| 青磁の小鉢 | 線なし | — | `kobachi` |

- 色を変えるときは `rim` で上書きする（例: `Q.plate(p, { rim: Q.RIM.kin })`）。線そのものをなくすときは `line: 'none'`。
- 古い名前 `INDIGO` は残してあるが、中身は こげ茶（`RIM.koge`）で、新しい絵では使わない。
- **具の色も青にしない**。魚の皮（さば・さんま・鮭）は銀の灰、アルミ箔とステンレスは青みのない灰、揚げ出し豆腐の鉢は飴にした。
- **確かめ方**: 書き出したあと、SVG の色（`fill` `stroke` `stop-color` の #rgb・rgb()）と、描いた画素（192px）の両方で、色相 190〜250 度・彩度のある色が残っていないかを調べる。2026-10-28 の書き出しでは日本の料理224品＋主食39品で 0 品（彩度 .04 以上でも 0）。
- 器ごとの色の比べ（いま→新）はオーナー向けの画像にした（代表20品）。

## 4. 部品（kit3q.mjs）

- **器**: `vessel`（共通形）、`hachi` `wan` `chawan` `donburi` `kobachi` `shiroBowl` `plate` `ovalPlate` `slabPlate` `pan` `donabe`、器の決まり（6.）で足した `asabachi`（浅めの小鉢） `fukazara`（洋・中華の深皿。sy に SYF） `soupCup`（スープカップと受け皿） `kozara`（小皿）。`plate` に `edge`（藍以外の縁の線）、`surface` は `V.sy` があればその比で面をつぶす
  - 鉢・椀などは `{ s, cx, cy, irx, iry, inside, above, shine() }` を返す。`inside` は口の形で切る。`above` は手前の口より上だけを見せる。`shine()` は口の左上の光。
  - 皿は `{ s, o }` を返す（o は見込みの面の中心）。
- **汁の面**（江口の描き方）: `surface(p, V, { drop, c, glow })`。中心が明るく縁が濃い面に、縁の陰と左上の照りをつける。`depthVeil` は奥を淡く、手前を濃くする。
- **角切り・豆・葉**（花森の描き方）
  - `prism`: 面の多角形を立ち上げ、手前の側面だけ描く。
  - `cube`: さいの目。汁に浮かせるときは `sink`。
  - `rangiri`: 乱切り。
  - `pea` `bean`: 豆。
  - `leaf`: 波打つ葉を面につぶしたもの。
  - `greensMound`: 葉物の山。
- **江口の描き方**（採用）: `glossLump`（煮物の具）、`thick`（平たい具の厚み。filter）、`slice3q`（平皿の肉）、`tarePool`（たれだまり）、`shine`（照りの弧と白い点）
- **江口の共通の形**: `soakLump`（染みる煮汁の色を変えられる煮物の具）、`cyl`（円柱。`sy` も指定できる）、`arcPts` `centered` `icho` `hangetsu`（いちょう切り・半月切り）、`clam` `shut` と色の組 `ASARI` `SHIJIMI`（貝）、`misoCloud`（味噌の雲）、`velvet` `swirl`（とろみとクリームのうず）、`eggRibbon`（溶き卵）、`strandMound`（千切りの山）
- **その他**
  - `lump`: 丸い具。
  - `slab`: 薄切り肉・切り身のような、厚みのある平たい具。
  - `shredMound`: 千切りの山。
  - `riceDome`: ご飯の山。輪郭は淡い影の線で締める。
  - `grainsPlane`: 平らな粒の面。
  - `negi` `steam` `shine` `cast` `dropOf` `blob` `byDepth` `at`
- 部品が足りないときは、まず自分の盛りつけファイルの中に作る。2人以上が使うものだけを部長に言って kit3q.mjs に入れる。kit3q.mjs を直接書きかえない（3人で同じブランチを使うため）。
