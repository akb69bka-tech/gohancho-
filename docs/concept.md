# ご飯帖の大元のコンセプト（オーナー決定 2026-10-28）

**毎日の献立を気軽に考えて、それを現実に出す（実際に作って食卓に出す）。**

仕様は、このコンセプトのために変えてよい。どの案でも守る約束:
1. 決めた献立は、本人の操作なしに変わらない（変えるときは確認を出し、元に戻せる）。
2. 苦手・アレルギーは、設定したその瞬間から必ず効く（どの画面から設定しても）。
3. 1品を変えても、ほかの料理は変わらない。
4. 決める → 買う → 作る → 食卓 → 記録 が途切れない（決めたらすぐ買い物メモが出る）。
5. 1画面に詰めこまない（縦に長くしない）。

出発点の声: 利用者モニター第1回（佐々木・田村）「今のままでは毎日は使わない」。

## オーナー決定（2026-10-28 13時台）
- 進め方は **A: 案1（土台を一本化）→ 案2（今日の一膳）**。
- 画面の構造はデザイン部の **② 一日の四段（一ノ瀬）と ③ 一日の帳面（桐山）** をもとに案2を形にする（統括の解釈。違えばオーナーが訂正）。
- 案2でタブから外す機能（食費メモ・画像でつくる・腕前と称号）は **消さずに記録の奥へ移す**。「機能は消さない」は「消さないが、タブからは外してよい」に改める（統括の解釈）。
