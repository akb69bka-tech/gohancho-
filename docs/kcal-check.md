# カロリーの目安 — 代表料理の確かめ

アプリの「約 ◯◯ kcal（1人分・目安）」（`kcalOf()`、10kcal 単位）を、代表料理 39 品について一般の目安とくらべた表です。
`node tools/tests/kcal-r1.mjs` の K2 が、同じ料理の値が範囲内かを毎回見ます。

- **一般の目安**は、よく見かける1人前の値を作り手の知識で書いたもの（**出典未確認**。料理の本・外食の表示などで幅があり、±2〜3割は普通にちがう）。
  公的な「料理ごとの値」は、この作業環境からは確かめられませんでした（`docs/kcal-sources.md` の「出典未確認」を参照）。
- 一般の目安は、アプリの値を見る前に決め、あとから合わせて動かしていません。
- **差が ±40% を超えたもの（⚠）**は、材料の1行ずつの換算（重さ・100g あたり kcal・吸油）を見直しました。
  換算の誤りは直し（下の「直したこと」）、残ったものは、どれも**レシピの1人分の量が一般の1人前より多い**ことが原因です（メモに量を書きました）。

## 直したこと（確かめの途中で見つけた換算の誤り）

- 英語の言葉が語の途中に当たっていた（regular の中の gula＝砂糖、sausage の中の sage＝香辛料、tamarind の中の tamari＝醤油、lemongrass の中の lemon など）。表の英語の言葉は語の頭からだけ当てるようにした（`kcB()`）。
- green / bell pepper（ピーマン・パプリカ）が「こしょう」に、lamb mince・pork balls などがほかの行に当たっていた。言葉の順と除く言葉を直した。
- 「油揚げ」が「油」に、「塩鮭」が「塩」に当たっていた。日本語の油・塩は名前の頭だけで見るようにした。
- 材料の名前に「(or 2 tbsp tomato paste)」「for the water」のような説明があると、説明の言葉に当たっていた。かっこ・for 〜・with 〜 を外して見て、水・香辛料に当たったら代表名（キー）で見直すようにした。
- 揚げ物の吸油を、ご飯・溶き卵まで含めた全部の重さに掛けていた（かつ丼が 1,200 kcal を超えた）。ご飯・麺・パンを除き、衣の種類で 13% / 7% / 5% に分けた。
- 「olive oil for poaching（ほとんど取っておく）」のように、たっぷりの油を全部足していた（スペインオムレツが 1,300 kcal 台）。揚げ油と同じ吸油の扱いにした。
- 2人分としては材料がとても多いレシピ（ルンダン 牛肉 800g・カスレ・パイなど）が 1,500〜2,700 kcal になっていた。1人分の重さの上限で人数を見積もるようにした（`docs/kcal-sources.md`）。
- 「納豆付属のたれ 2袋」が納豆 200g になっていた。たれの行を足した（1袋 6g）。
- 栗（Velouté de châtaignes）が表になく、目安を出せなかった。栗の行を足した。

## 数字を出せない料理（国別）

21か国 2,186 品のうち、**目安を出せない料理は 0 品（どの国も 0%）**。
1人分が 30 kcal 未満で「30 kcal 未満」と出す料理は 7 品（日本 5：きゅうりの浅漬け・白菜の浅漬け・玉ねぎのコンソメスープ・菜の花のからし和え・ほうれん草のおひたし／中国 1：えびと海苔のスープ／フィリピン 1：ゆでオクラ）。

ただし「出せる」は「重さの 7 割以上を表の食材と量で推せた」という意味で、値が正しいことの保証ではありません（表の値はすべて出典未確認）。
