# 仲間はずれの点検（category-audit）

品質保証部 八木 千景。2026-10-29。

オーナーの指摘（「おかゆだけを選んだのに、きつねうどんが入っている。仲間の中に仲間でないものが入っていたら、ちゃんと分かるはず」）を受けて、
「仲間の中に、仲間でないものが入っている」を機械で見つける点検を作った。`tools/qa/run-all.sh` の既定（quick）と `--full` の両方に入っていて、**1件でもあれば落ちる**。

```
BASE=http://localhost:<ポート>/ node tools/qa/category-audit.js          # 21か国（1分ほど）
CCS=JP RUNS=8 OUT=/tmp/ca.json node tools/qa/category-audit.js           # 国を絞る・回数を増やす・結果を JSON に書く
```

## 調べる場面

21か国（JP US GB FR DE IT ES PL TR EG IN CN TW KR TH VN ID PH MX BR PE）それぞれで、乱数（SEED と国から決まる）を変えながら次を作り、出た料理を全部見る。

| 場面 | 中身 |
|---|---|
| 気分 | その国で選べる気分すべて（日本: おまかせ・20分以内・ラクの日・お弁当・和食・洋食・中華・韓国エスニック・魚の日・がっつり肉・おかゆの日。各国: おまかせ・20分以内・ラクの日・お弁当・魚の日・がっつり肉）× 品数（1・2・2〔汁ものなし〕・3・4・5・6）× 4回 |
| 主食 | その国の主食の選び方すべて（日本はおかゆも）× 気分（おまかせ・20分以内・魚の日）× 品数 3・4 |
| かえる | 気分すべて × 品数 4・6 の献立で、すべての席について、絞りこみ なし・冷蔵庫の物で・20分以内・魚の日・おかゆの日（主菜の席で、粥のある国だけ）の候補 |
| あと1品 | 気分すべて × 品数 3・5 の献立で、あと1品の候補 |
| 1週間プラン | 副菜・汁ものも付けて4回。気分ごとに「その気分の日に作る」4回ずつ |
| プランのある日 | 1週間プランがある日に、気分（明日からにした気分）を選んで開く |
| 明日の献立 | 明日からにした気分ごと |
| アレルギー・苦手 | 卵・乳・小麦／えび・かに・魚／苦手「魚」／大豆・ごま＋苦手「豚肉」の4通り × 気分すべて × 品数 3・5（主食も） |

席は主菜・副菜・汁もの・ご飯（主食）。国を組み合わせた席は、本人が選んだ国の料理なので、気分の絞りこみは見ない。

## 直したもの（gohancho/index.html）

1. `OKAYU_QUICK` からきつねうどんを外した（先にコミット e4fc4590。統括が claude/int に取りこみ済み）。おかゆの日の主菜は、おかゆ・雑炊・粥だけ。候補がないときも、ほかの料理・麺で埋めない。粥の主菜がない15か国では、かえるの「おかゆの日」を出さない。
2. かえるの絞りこみ（20分以内・魚の日）は、選んでいる気分に**重ねる**（魚の日に「20分以内」→ 20分以内の魚の料理）。前は絞りこみが気分を置きかえていた。おまかせの日・「おかゆの日」の絞りこみは今までどおり。合う料理がないときは「合う料理がありません」。
3. 主食が「おかゆ」の日は、ご飯もの・麺を主菜にしない（今日の献立・1週間プラン。候補がないときは今までどおり）。
4. 和食・洋食・中華・韓国エスニックの日は、副菜・汁もの・2品目の主菜も、そのなかまを先に出す（韓国エスニックの日は中華も可）。その席に合う料理がないときだけ外す。
5. お弁当の日に、主食になる副菜（じゃがいも・パンなど。アメリカ・イギリスの主食「なし」の日）を選ぶときも、お弁当向きの料理から選ぶ。
6. 副菜・汁ものを選ぶとき、ラクの日・お弁当の日の絞りこみを「似ていない料理」の絞りこみより先にかけ、アレルギー・苦手・今は出さない料理は先に外す（似ていない料理を残すために、条件に合わない料理が入っていた）。おまかせなど、ほかの気分の選び方は変わらない。

7. 1週間プラン（作る・選び直す・副菜/汁もの）は、今日の気分に左右されない（`poolForMood('主菜', 'all')`）。
8. 1週間プランのある日に開いたとき、プランの主菜が選んでいる気分（おかゆの日・魚の日・20分以内など）に合わなければ、今日の献立には入れない（「献立にする」の案内は今までどおり出る）。
9. 作ったばかりの案にプランの主菜を入れたとき、それが汁けの多い料理（鍋など）・イタリアの Primo なら、汁ものの席は空ける（newMenu と同じ決まり）。

決めた献立は変えていない（まだ決めていない案の作り方だけ）。アレルギーの照らし合わせは変えていない。画面の文字は足していない。
