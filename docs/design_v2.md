# デザイン v2 方針（全員共通）
目的: アプリのコンセプト（お膳の献立帳・藍の1色・明朝の見出し・やさしい言葉・端末内完結）は変えずに、「開いた瞬間に変わった」と分かる見た目と使い心地にする。

## 変えないこと
- 藍を主色にする（山吹は「変えたところ・プラス」の目印だけ）。見出しは明朝、本文は角ゴシック。
- 機能は消さない。事実でないことは表示しない。ほかの料理が連動して変わる変更は禁止。
- 新しい外部通信・有料サービスは使わない。

## 変えること（全体の土台は三宅が担当し、他の人はこの土台の変数・部品を使う）
1. **余白と文字の段階を整理**: 余白は 4/8/12/16/24/32px、文字は 12/14/16/20/24/32px の6段に統一。行間 1.6。
2. **カード**: 角丸 16px、影はやわらかく1段、境界線は薄く。カードの中の見出し・本文・操作の並び順を全画面でそろえる。
3. **ボタンは3種類だけ**: 主（藍の塗り・1画面に1つ）、副（藍の枠）、文字だけ。押せる高さは 48px 以上。押したときに少し沈む。
4. **主役を1つに**: 各画面で「いちばん押してほしい1つ」を大きく、画面下の手が届く場所に固定する（例: 今日タブは「これに決める」）。それ以外は控えめに・まとめる。
5. **提案の見せ方**: 料理の絵を大きく、名前・時間・主な食材・「なぜこの料理か」の一言を、ひと目で読める順に。かえるは料理ごとに、すぐ押せる位置に。
6. **動き**: 切り替えはやさしいフェード・入れ替わった料理だけが小さく動く。reduced-motion では止める。ガタつきは禁止（tools/qa/layout-shift.js を通す）。
7. **暗い表示（ダーク）・大きい文字・狭い画面・17言語・RTL** で崩れない。

## 作業のしかた
- 担当の画面だけを触る。CSS の共通変数（:root）と共通部品（ボタン・カード・チップ）は三宅だけが変える。他の人は使うだけ。
- 変更前と変更後のスクリーンショット（JP ja・US en・EG ar、390px、ライト/ダーク）を scratchpad/design_v2/<担当>/ に保存して報告に載せる。
- tools/qa/run-all.sh --quick と、tools/qa/layout-shift.js --quick、tools/qa/viewport.js を通す。
