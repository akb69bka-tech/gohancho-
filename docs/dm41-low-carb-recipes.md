# 糖質ひかえめモードで回すために足した料理（dm41）

オーナー指示（11/11）「糖尿病の人が食べられるレシピの開発と、そのモードの追加」で、「糖質ひかえめ」モードのときに
1週間（主菜 7・副菜 14・汁もの 7 以上）を国ごとに品切れせず回すために足した料理の一覧です。
写真・イラストはまだありません（アプリは「画像なし」の自動の絵で出します）。**制作部への依頼: 下の「必要な画像の内容」で、ほかの料理と同じ形式（img/dish/<ID>.svg・manifest.json）の絵を作ってください。**

- 料理のデータ: `gohancho/packs/<国>.js`（英語）、訳: `gohancho/packs/i18n/<国>.ja.js` と、その国の言葉（`<国>.<言語>.js`）

- 健康・効き目の言い方はしていません（`tools/tests/health-claims.mjs`）
