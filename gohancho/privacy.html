プライバシーポリシー

わが家のご飯帖（以下「本アプリ」）　制定日: 【公開日を記入】　最終更新: 2026年11月23日

本アプリは、献立・レシピ・記録をお使いの端末の中で動かす料理アプリです。運営者は、利用者の個人情報を集めません。以下に、本アプリが扱う情報と、外部との通信をすべて書きます。

1. 運営者が集めない情報（端末の中だけに保存するもの）

次の情報は、お使いの端末の中（iPhone アプリではアプリの保存領域、ブラウザではそのブラウザの保存領域）にだけ保存されます。運営者のサーバーに送ったり、運営者が見たりすることはありません。運営者は利用者のサーバーやアカウントを持っていません。

  • 献立の記録、お気に入り、保存した献立、1週間の予定、買い物メモ
  • 冷蔵庫の材料、いつも家にある食材、作り置き・残り物のメモ、食費メモ
  • 苦手な食材、アレルギー、食の決まり（豚肉・お酒・肉や魚など）、人数・国・言語・文字の大きさなどの設定
  • 家族のプロフィール（呼び名と、その人の苦手な食材・アレルギーなど）と、家族から届いた「食べたいもの」
  • 追加したレシピ、撮影・登録した料理の写真（わが家の一枚・アルバム）
  • 「よく行くスーパー」に登録した店の名前・地域・郵便番号・特売日と、入力した特売の情報（店のページの URL は、ご自身で開くためのリンクとして表示するだけで、本アプリが読みこむことはありません）
  • お知らせ（通知）の予約、タイマー

アレルギーや食の決まりの情報も、端末の中だけで献立を選ぶために使い、外部には送りません。

2. 外部との通信と、第三者に渡る情報

本アプリが外部と通信するのは、次の場合だけです。

通信先いつ・何のため送られる情報
Apple（App Store）・RevenueCat, Inc.iPhone アプリ版で、有料プラン「ご飯帖プラス」を購入・復元するときと、購入状況を確かめるとき（Web 版は無料のため使いません）購入の確認に必要な情報（RevenueCat が作る匿名の利用者 ID・購入履歴など）。お支払いは Apple が扱い、運営者はカード番号などのお支払いの情報を受け取りません
GitHub（運営者の設定ファイル）アプリを開いたとき、お知らせの小さな設定ファイルを読みこむ。読みこめなくてもアプリは使えます通信に伴う IP アドレス等（利用者を特定する情報は送りません）
Wikipedia / Wikimedia Commonsアプリに同梱した料理の絵が読み込めなかった場合のみ、料理の参考写真（端末の中でイラスト化して表示）と、その撮影者・ライセンスの取得料理名（記事名）と、通信に伴う IP アドレス等
YouTube / Google 検索「作り方の動画を探す」「完成写真を画像検索」を押したときのみ（ブラウザで開きます）料理名（検索語）と、通信に伴う IP アドレス等
ご自身で選んだ送り先のアプリ（LINE・WhatsApp・メールなど、または iPhone の共有の画面で選んだアプリ）献立・買い物メモ・レシピ・「何が食べたい？」を家族に送るボタンを押したときのみ送ると決めた文章（献立・料理名・買い物メモなど）。送った内容の扱いは、そのアプリの決まりに従います
GitHub Pages（家族に送るリンクのページ: 「何が食べたい？」「食べたいもの」）家族が、届いたリンクを開いたとき通信に伴う IP アドレス等。料理の候補などはリンクの「#」より後ろに入っていて、サーバーには送られません
ご自身のメールアプリ「ご意見・不具合を送る」を押したときのみ（ボタンが出ているとき）ご自身で書いた文と、アプリの版・国・言語・端末の種類（メールの本文に入り、送る前に見て消せます）

各サービスでの情報の扱いは、それぞれのプライバシーポリシーに従います。運営者は、上の表のほかに、利用者の情報を第三者に売ったり渡したりしません。

3. 広告・解析・追跡

本アプリは、広告を表示しません。利用状況の解析ツールや、ほかのアプリ・サイトをまたいで利用者を追跡するしくみ（トラッキング）も使っていません。

4. カメラ・写真・マイクの使い方

「作った料理を撮って登録」を押したときだけ、カメラまたは写真ライブラリを使います。選んだ写真は縮小して端末の中に保存し、外部には送信しません。

「冷蔵庫の写真から選ぶ」で撮った（選んだ）写真は、食材の候補を出すためだけに使います。iPhone アプリでは、写真の読み取りを iPhone に入っている Apple の画像分類機能（Vision）でこの端末の中だけで行い、写真は外部に送信せず、保存もしません（画面を閉じると破棄されます）。読み取りに使えない環境では、写真を見ながら自分で食材を選ぶ画面になります。出た候補は、確認して「冷蔵庫に入れる」を押すまで冷蔵庫には入りません。iPhone アプリでチラシを撮ったときも、写真を端末の中で読み取るだけで、外部に送信せず、保存もしません。

マイク・音声認識: 「声で入力」を押したとき、および料理中に「ハンズフリー」をオンにしている間（「次」と言って手順を進めるため）だけ、マイクを使います。ハンズフリーはオフにするか、画面を離れると止まります。話した声は、文字にするために端末の音声認識機能（iPhone では Apple の音声認識。音声が Apple のサーバーで処理されることがあります。Android の Chrome などブラウザで使うときは、そのブラウザの音声認識で、Google などのサーバーで処理されることがあります）に渡され、その扱いは Apple・ブラウザ提供元のプライバシーポリシーに従います。このアプリは声の録音を保存せず、文字にした結果（食材名・料理名）だけを端末の中で使います。

カメラ・写真・マイク・通知は、使う場面で iPhone の許可を求めます。許可しなくても、ほかの機能はそのまま使えます。許可は iPhone の「設定」→「ご飯帖」でいつでも変えられます。

5. 子どもの情報

本アプリは、子ども向けに作ったアプリではありません。運営者は、年齢にかかわらず利用者の個人情報を集めないため、子どもの個人情報も集めません。購入は Apple アカウントで行われ、その扱いは Apple の決まりに従います。

6. 保存する期間と、消し方

端末の中の情報は、利用者が消すまで、その端末に残ります。運営者は情報を持っていないため、運営者の側で保存する期間はありません。

  • 記録・お気に入り・材料・常備品・わが家のレシピ・設定など: 設定 › データ の「データの引っ越し・バックアップ」の中の「すべてのデータを消す」で消せます。ただし、無料期間を始めた日と購入の状態は、お試しのやり直しを防ぐため消しません。
  • 料理の写真（わが家の一枚・アルバム）: 「すべてのデータを消す」では消えません。アルバムの「この写真をアルバムから消す」で1枚ずつ消せます。
  • すべて: iPhone アプリを削除すると、端末の中のデータはすべて削除されます。ブラウザで使っている場合は、ブラウザの設定でこのサイトのデータを消すと削除されます。
  • 購入の情報: Apple と RevenueCat が、それぞれの決まりに従って保存します。購入の管理と解約は、iPhone の「設定」→ 自分の名前 →「サブスクリプション」から行えます。

7. 利用者の権利

運営者は利用者の個人情報を集めず、保存もしていないため、運営者の手元に、見せる・直す・消すことのできる個人情報はありません。購入の情報については Apple にお問い合わせください。そのほかのご質問は、下のお問い合わせ先へどうぞ。
