わが家のご飯帖 サポート

毎日の献立を、お膳ごと提案する料理アプリです。

よくある質問

わからないことは、下の「お問い合わせ」からどうぞ。ボタンや欄の名前は、アプリの画面の名前に合わせています。

料金・解約

料金はかかりますか？

ご飯帖は、有料プラン「ご飯帖プラス」でお使いいただくアプリです（iPhone 版・Web 版とも）。はじめて登録した最初の1か月は無料で、次の月から月額300円（税込・自動更新）です。iPhone 版のお支払いは Apple、Web 版のお支払いは決済会社が扱います。いまは販売の準備中のため、iPhone 版・Web 版ともすべての機能を無料でお使いいただけます（販売を始めたら、ここでお知らせします）。

いつから料金がかかりますか？

無料の1か月が終わったときからです。期間が終わる24時間前までに解約しなければ自動で更新され、お支払いは Apple アカウントに請求されます。

ご飯帖プラスを解約したい

iPhone の「設定」→ 一番上の自分の名前 →「サブスクリプション」→「ご飯帖」から解約できます。購読中は、アプリの「ご飯帖プラス」の画面の「プランの管理・解約」からも開けます。解約しても、期間の終わりまでは使えます。

無料の1か月だけ使って、やめられますか？

はい。無料期間が終わる24時間前までに解約すれば、料金はかかりません。

解約したら、記録は消えますか？

消えません。記録や設定は、この端末の中に残ります。

無料期間のあと、払わないとどうなりますか？

無料期間が終わって続けない場合、献立などの画面が使えなくなります。そのときも、記録があれば「これまでの記録を書き出す」でファイルにできます。

返金してほしいです

お支払いと返金は Apple が扱います。Apple の「問題を報告する」の手続きをご覧ください。

機種変更したら購入はどうなりますか？

同じ Apple アカウントでサインインし、新しい iPhone でアプリの「購入を復元」を押すと、続けて使えます。献立の記録は、下の「機種変更したら、記録はどうなりますか？」の手順で移せます。

Web 版と iPhone 版のちがいは？ Android でも使えますか？

Web 版はブラウザで開いて使えます。料金は iPhone 版と同じです（最初の1か月無料・その後 月額300円。Web 版の支払い・解約のしかたは、販売を始めるときにここに書きます）。iPhone 版と Web 版の購入は別々です。Android やパソコンでは Web 版を使います（設定 › プラン・その他 の「ホーム画面に追加する」などで、アプリのように開けます）。毎日のお知らせ（通知）や、冷蔵庫・チラシの写真の自動の読み取りは iPhone 版で使えます。Android のアプリはありません。

データ・機種変更

記録やデータはどこに保存されますか？

お使いの端末の中だけです。アカウントの登録はなく、記録を外へ送ることもありません。料理の写真も、この端末の中だけに保存されます。くわしくはプライバシーポリシーをご覧ください。

機種変更したら、記録はどうなりますか？

記録・お気に入り・設定などは、この端末の中だけに保存されています。前のスマホで、設定 › データ の「ファイルで書き出す」を押してファイルを作り、新しいスマホで、同じ 設定 › データ の「データの引っ越し・バックアップ」を押してひらき、中の「ファイルから読み込む」を押して、そのファイルを選んでください。その欄の文字をコピーして、新しいスマホの同じ欄に貼りつける方法もあります。写真（わが家の一枚・アルバム）は移りません。

家族のスマホでも、同じ献立を見られますか？

端末どうしを自動で同じにする機能（同期）はありません。決めた献立や買い物メモは、「家族に送る」で送れます。

アカウントや個人情報の登録は要りますか？

要りません。名前やメールアドレスを入れずに使えます。

データを全部消したいです

設定 › データ の「データの引っ越し・バックアップ」をひらき、「すべてのデータを消す」→「すべて消す」で、記録・お気に入り・材料・設定・料理の写真（わが家の一枚・アルバム）などを消せます。元には戻せません。お試しの開始日と購入の状態は残ります（購入は App Store が管理しています）。同じ端末でお試しを何度も始め直せないようにするためです。

アレルギー・食の決まり

アレルギーの食材は、確実に外れますか？

設定で選んだアレルゲンを材料の名前で調べ、合わない料理を出さないようにしています。ただし、材料の名前からの目安で、保証ではありません。加工品（だし・ルウ・調味料など）は、🔍 の印の所で、袋の表示を確かめてください。重いアレルギーの方は、必ず原材料表示・医師の指示に従ってください。

家族ひとりずつ、アレルギーを入れられますか？

はい。設定 › 家族・アレルギー の「家族を追加」で家族の人を足し、その人のアレルギーを選べます。合わない料理があるときは「（名前）に合わない料理があります」と出ます。

どのアレルゲンを選べますか？

日本の表示が義務の9品目（特定原材料）と、表示をすすめる20品目のほか、ほかの国でよく使われる分けかたも合わせて、43のなかまから選べます。

ハラール・ベジタリアン・ヴィーガンに合わせられますか？

はい。設定 › 苦手・食の決まり の「まとめて選ぶ（食の決まり）」で選べます。食の決まりに合わない可能性のある料理を外す目安で、保証ではありません。ベジタリアン向けでは卵・乳製品は外しません。食べない場合は、出てくる「卵も外す」「乳製品も外す」を押してください。

苦手な食材やアレルギーがある

設定の「苦手な食材」で選んだ食材は、ほかの食材に置き換えられる料理なら置き換えて提案します（例: 豚肉→鶏肉）。置き換えられない料理は献立に出しません。アレルギーがある場合は、調味料や加工品の原材料も必ずご自身でお確かめください。

家族への共有

献立や買い物メモを家族に送れますか？

はい。今日の献立や1週間の主菜の「送る」のボタンから送れます。国によって、日本・タイ・台湾では LINE、イギリス・フランス・ドイツ・ブラジル・インドなどでは WhatsApp のボタンが出ます。「ほかのアプリで送る」「コピーする」も使えます。

LINE や WhatsApp のボタンが出ません

中国・韓国・アメリカ・フィリピン・ポーランド・ベトナムなどでは、そのアプリのボタンは出ません。「ほかのアプリで送る」で送り先のアプリを選ぶか、「コピーする」で文を写して、使っているアプリに貼りつけて送ってください。

使い方

同じ料理ばかり出ませんか？

「この献立に決定」や「今日作った」で記録すると、設定した日数（初期値10日）以内に作った料理は出さず、前日と同じ肉・魚やジャンルも続かないように選びます。日数は 設定 › 献立 で変えられます。

1品だけ替えたいです

料理の「かえる」を押すと、候補から選べます。決めたあとの献立は、「決めた献立を変えますか？」と確かめてから、押した1品だけを替えます。ほかの料理は変わりません。

人数や品数を変えたいです

人数は、設定 › 家族・アレルギー の「何人分つくるか」で変えられます（1〜15人）。品数は、設定 › 献立 の「ふだんの品数」か、今日の献立の「条件を変える」で変えられます。

1週間分の献立はどこで作りますか？

今日の献立の画面を下へ送ると「1週間の主菜」があります。ひらいて「1週間分を考える」を押してください。

買い物メモの使い方を教えてください

献立を決めると、買う物の一覧が出ます。家にある物は「家にある」を押すと、買う物から外れます。「料理ごと」「売り場ごと」で並べかえることもできます。

近くの店で手に入らない食材が出ます

設定 › 苦手・食の決まり の「手に入りにくい食材」に足すと、その食材を使う料理は出なくなります。

文字を大きくしたいです

設定 › 表示 の「文字の大きさ」で、「ふつう」「大きい」「もっと大きい」から選べます。はじめて開いたときの画面でも選べます。

電波の弱い所や圏外でも使えますか？

一度、電波のある所で開いておくと、アプリと使っている国のレシピが端末に保存され、電波がなくても開けます。ほかの国の料理をさがすときや、言葉を変えたときなどは、電波が要ることがあります。

日本語以外の言葉で使えますか？

18の言葉で使えます。設定 › 表示 の「表示する言語」から変えられます。

作り方を読み上げてくれますか？

はい。作り方の画面の「声で読み上げ」を使うと、手順を読み上げます。「次の手順」を押すと、次を読みます。

毎日のお知らせは出せますか？

iPhone 版で使えます。設定 › プラン・その他 の「毎日のお知らせ」で時間を選んでください。1週間の献立があると、その日の主菜と主な材料をお知らせします。iPhone の「設定」→「ご飯帖」→「通知」で、通知を許可してください。

糖質や塩分をひかえたいです

設定 › モード で「糖質ひかえめ」や「減塩（塩分の目安を表示）」を選べます。変わるのは料理の選び方と目安の表示です。

ほかの国の料理を見たい

下の「世界のレシピ」から国を選ぶと、その国の家庭料理を見られます。毎日の献立は、設定で選んだ国のままです。

料理の絵について

料理の絵は、AI で作成したイメージです。実際の料理・盛りつけとは異なります。絵はアプリに入っているので、通信しなくても表示されます。「作った料理を撮って登録」で、ご自身の写真にもできます（端末の中だけに保存されます）。

お問い合わせは、GitHub の ご飯帖 サポート窓口（Issue #1） にお書きください。端末の機種と iOS（または使っているブラウザ）のバージョン、困っている内容を添えてください。書きこむには GitHub のアカウント（無料）が要ります。書いた内容は誰でも見られるので、名前・住所・メールアドレスなどの個人の情報は書かないでください。
