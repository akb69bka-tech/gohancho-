## 1. Apple に開発者登録する（Apple Developer Program）

1. iPhone または Mac で https://developer.apple.com/jp/programs/enroll/ を開く
2. 「登録を開始」→ Apple ID でサインイン（2ファクタ認証をオンにしておく）
3. 「個人 / 個人事業主」を選ぶ（法人なら「組織」。D-U-N-S 番号が必要で日数がかかります）
4. 氏名・住所をローマ字で入力（※ App Store の「販売元」にこの本名が表示されます）
5. 本人確認（画面の指示どおり。身分証の撮影を求められることがあります）
6. 年会費を支払う（99米ドル／年）
7. 「ようこそ」のメールが届いたら完了。**承認まで通常 1〜3日**。待っている間に「2」と「3」を進められます

> 出典: Apple Developer Program https://developer.apple.com/jp/programs/ （費用・手順は変わることがあります）

## 3. Mac の準備とアプリの組み立て

### 3-1. 道具を入れる（初回だけ。合計30〜60分、ほとんど待ち時間）

1. **Xcode**: Mac の App Store で「Xcode」を検索してインストール（10GB 以上。時間がかかります）。入れたら一度起動して、利用規約に同意し、追加部品のインストールを済ませる
2. **Node.js**: https://nodejs.org/ja から **LTS** 版（**22 以上**。Capacitor 8 に必要）をダウンロードしてインストール
3. **Git**: ターミナルを開いて `git --version` と打ち、インストールを聞かれたら「インストール」

> ターミナルの開き方: Finder → アプリケーション → ユーティリティ → ターミナル（または Spotlight（⌘＋スペース）で「ターミナル」と入力）

### 3-2. アプリのファイルを Mac に持ってくる

ターミナルに次を1行ずつ貼って Enter:

```bash
cd ~/Documents
git clone https://github.com/akb69bka-tech/gohancho-.git
cd gohancho/ios-app
npm run setup
```

`npm run setup` が「部品の取りこみ → iPhone 用プロジェクトの作成 → アイコンと起動画面の作成 → 審査に必要な設定 → Xcode を開く」まで自動でやります（5〜10分）。途中で止まったら、ターミナルの最後の20行を Claude に貼ってください。

> すでに `~/Documents/gohancho` がある場合は、`cd ~/Documents/gohancho && git pull` のあと `cd ios-app && npm run setup`。

### 3-3. Xcode での設定（開いたら。10分）

Xcode の左の一覧で一番上の **「App」**（青いアイコン）をクリック → 中央に設定画面が出ます。

| タブ | すること |
| --- | --- |
| **Signing & Capabilities** | 「Team」で、自分の名前（Apple Developer の登録名）を選ぶ。「Automatically manage signing」にチェック |
| 同じ画面 | 左上の **「+ Capability」** → 「In-App Purchase」をダブルクリックして追加 |
| **General** | 「Supported Destinations」が iPhone だけになっているか確認（iPad があれば選んで − で削除）。「Version」が `1.1.0`、「Build」が `1` |
| **プライバシー マニフェスト** | 左の一覧の App → App フォルダに **PrivacyInfo.xcprivacy** があるか確認（`npm run setup` が作って自動で足します）。無いときは、Finder で `ios-app/ios/App/App/PrivacyInfo.xcprivacy` を Xcode の App フォルダへドラッグし、出てきた画面で **「Add to targets: App」に印** を付けて Finish。右側の「Target Membership」で App に印があれば OK。これが無いと App Store Connect で「プライバシー マニフェストがない」と警告・却下されます（GitHub Actions のビルドは、無いと止まるようにしてあります） |
| **Info** | 「Localizations」の ＋ で、次の17言語を追加: English, French, German, Italian, Spanish, Portuguese (Brazil), Polish, Turkish, Arabic, Hindi, Indonesian, Filipino, Thai, Chinese (Simplified), Chinese (Traditional), Korean, Vietnamese（日本語はすでにあります）。マイク・カメラ・写真の許可の文言は、日本語の人には日本語、それ以外の言語の人には英語で出ます（`npm run setup` が `en.lproj` / `ja.lproj` の InfoPlist.strings を入れます） |

### 3-4. 自分の iPhone で動かしてみる

1. iPhone をケーブルでつなぐ。iPhone で「このコンピュータを信頼」→ 信頼
2. Xcode 上部の端末名を、自分の iPhone に切りかえる
3. ▶（再生ボタン）を押す。初回は iPhone の「設定 → 一般 → VPN とデバイス管理」で自分の Apple ID を「信頼」する必要があります
4. iPhone でアプリが開き、国を選ぶ画面が出れば成功。献立・写真登録・通知（設定 → 毎日のお知らせ）を試す
5. この時点では課金の鍵を入れていないので、購入画面は出ず、すべて無料で使えます（正常）

## 4. App Store Connect にアプリと課金を登録する

App Store Connect（https://appstoreconnect.apple.com/ ）は「App Store に出す情報を入力する管理画面」です。開発者登録の承認後に入れます。

### 4-1. 契約・口座・税務（これをしないと課金が売れません）

1. 左メニュー **「ビジネス」**（または「契約/税金/口座情報」）
2. **有料 App** の契約を「リクエスト」→ 規約に同意
3. **銀行口座**を登録（通帳の口座番号・支店コード。金融機関コードは画面で検索）
4. **税務情報**: 日本在住者は「米国の税務フォーム W-8BEN」を求められるのが一般的です。「米国以外の居住者」として進め、マイナンバー（TIN）を入力（**要確認**: 画面の案内に従ってください）
5. 連絡先（法務・財務・マーケティング）は全部自分でよい

### 4-2. アプリを作る

1. **「マイ App」** → 左上の **＋** → **「新規 App」**
2. 入力:

| 欄 | 入れる内容 |
| --- | --- |
| プラットフォーム | iOS |
| 名前 | わが家のご飯帖 献立と買い物リスト |
| プライマリ言語 | 日本語 |
| バンドル ID | `io.github.akb69bka.gohancho`（一覧に無ければ「3-3」で Xcode の Signing を設定して ▶ を一度実行すると現れます。それでも無ければ https://developer.apple.com/account/resources/identifiers/list で ＋ → App IDs → App → Explicit に同じ文字列を登録） |
| SKU | gohancho-ios-001 |
| ユーザアクセス | フルアクセス |

3. 「作成」

### 4-3. サブスクリプション（課金）を作る

1. 作ったアプリ → 左メニュー **「サブスクリプション」**（「収益化」の中）
2. **サブスクリプショングループ**を作成 → 参照名: `ご飯帖プラス`
3. グループの中で **「＋」** → 下の表の **2つ（月額と年額）** を作る（オーナー決定 2026-10-31: 月額300円・年額3,000円。年額は最初から誰でも選べる）:

| 欄 | 1つ目（月額） | 2つ目（年額） |
| --- | --- | --- |
| 参照名 | ご飯帖プラス 月額 | ご飯帖プラス 年額 |
| 製品 ID | `gohancho_plus_monthly` | `gohancho_plus_yearly` |
| サブスクリプション期間 | 1か月 | 1年 |
| 価格（日本） | 300円（「価格を追加」→ 基準の国: 日本 → 一覧から 300円を選ぶ） | 3,000円（同じく 3,000円を選ぶ。月額×12＝3,600円より600円安い） |
| ほかの国の価格 | Apple の自動の価格のままでよい。出た金額を `世界配信の計画と収支試算.md` の「各国の価格の目安」の「要確認」に書き写す | 同左。どの国でも年額が月額の12か月分より安いことを確かめる |
| App Store ローカリゼーション（日本語） | 表示名: `ご飯帖プラス 月額` ／ 説明: `献立・買い物メモ・世界のレシピが使えます` | 表示名: `ご飯帖プラス 年額` ／ 説明: `1年分をまとめて。月額の12か月分よりお得です` |
| 同（英語 English (U.S.)） | Display name: `Gohancho Plus Monthly` ／ Description: `Meal plans, shopping lists and world recipes` | `Gohancho Plus Yearly` ／ `One year at once, for less than 12 months` |
| 審査に関する情報 | スクリーンショット: iPhone でアプリの「設定 → ご飯帖プラスを見る」の画面を撮って添付。メモ: `Monthly plan with 1-month free trial.` | スクリーンショット: 同じ画面（月額と年額が並んでいる）。メモ: `Yearly plan with 1-month free trial. Shown to every user.` |

> 300円・3,000円が一覧にない場合は、いちばん近い金額を選び、オーナーに確認する（Apple の円の価格の刻みは、公式の一覧で確かめられていない＝要確認）。

4. **お試しオファー（無料の1か月）を月額と年額の両方に付ける**:
   1. 月額の製品を開く → 「サブスクリプションの価格」→ **「お試しオファー」の ＋**（「オファーを設定」）
   2. 国または地域: **すべて**（配信する国すべて）→ 開始日: 今日、終了日: なし
   3. 種類: **無料トライアル** → 期間: **1か月** → 確認
   4. 年額の製品を開いて、1〜3 を同じようにする（期間1年の製品にも「1か月の無料トライアル」を選べる）
   - Apple の決まり: お試しオファーは製品ごとに作れるが、**1人が使えるのは同じグループの中で1回だけ**（月額で使った人が年額に替えても、もう一度は無料にならない）。出典: https://developer.apple.com/help/app-store-connect/manage-subscriptions/set-up-introductory-offers-for-auto-renewable-subscriptions
   - アプリは、App Store に登録したお試しの長さと「お試しを使えるか」を RevenueCat から読んで表示する（使えない人には「無料」と出さない）
5. グループの「サブスクリプショングループのローカリゼーション」で、日本語の名前 `ご飯帖プラス`、英語 `Gohancho Plus` を入れる
6. 各製品のステータスが「提出準備完了」になっていれば OK（「メタデータが不足」なら赤い項目を埋める）
7. **はじめてのサブスクリプションは、アプリのバージョンと一緒に審査に出す**: 「7-2」のバージョンの画面の「App 内課金とサブスクリプション」で、月額と年額の2つを選んで付ける

> **課金はいつ始まるか**: App Store Connect で価格を設定し、アプリが審査を通って公開され、アプリに RevenueCat の鍵（5-2）が入ったときから、iPhone アプリ版だけで始まる。Web 版は `billingMode: 'off'` のまま無料（オーナー決定 2026-10-31）。

### 4-4. 配信する国（20か国＋そのほかの国。中国本土は外す）

オーナー決定（2026-10-31）: アプリが対応している21の国・地域のうち、**中国本土を除く20か国**に出す。App Store では中国本土だけを外し、ほかの国・地域はすべて選ぶ（全世界配信。対応国以外の人は英語の画面で使える）。

1. App Store Connect →「アプリ」→ ご飯帖 → 左メニューの **「価格および配信状況」**（アプリ本体の。アプリ本体の価格は **無料** のまま）
2. 「配信可能な国または地域」（「App の配信状況」）の **「配信可能な国または地域を管理」**（または「編集」）を押す
3. **「すべて選択」**（全部にチェック）を押す
4. 一覧の **「中国本土」のチェックだけを外す**（中国本土での配信には ICP 備案という中国政府への届け出が必要。オーナー決定で外す）
5. 次の20か国にチェックが入っていることを目で確かめる: 日本・アメリカ・イギリス・フランス・ドイツ・イタリア・スペイン・ポーランド・トルコ・エジプト・インド・台湾・韓国・タイ・ベトナム・インドネシア・フィリピン・メキシコ・ブラジル・ペルー
6. 「新しい国または地域を自動で追加する」の欄があれば、オンのままでよい（あとで Apple が国を増やしたときも配信される）
7. **「保存」**（「完了」）
8. サブスクリプションの製品（月額・年額）の「配信状況」も、同じく中国本土以外になっているかを確かめる（各製品の「サブスクリプションの配信状況」。アプリ本体と合わせる）

> 画面の名前は App Store Connect の更新で変わることがある。見つからないときは「価格および配信状況」のページの中で「国」「地域」を探す。

## 5. RevenueCat の設定とアプリへの反映

RevenueCat は「購入が有効かどうかを安全に確かめてくれるサービス」です（月2,500米ドルの売上まで無料。出典: https://www.revenuecat.com/pricing/ ）。

### 5-1. RevenueCat 側

1. https://app.revenuecat.com/ でアカウント作成（Google でログイン可）→ 新規プロジェクト「Gohancho」
2. **Apps** → ＋ → App Store → App name: Gohancho、Bundle ID: `io.github.akb69bka.gohancho`
3. 同じ画面の **In-app purchase key**: App Store Connect の「ユーザとアクセス」→「統合」→「App 内課金」で鍵を作り（.p8 をダウンロード）、RevenueCat にアップロード。Issuer ID も貼る
4. **App Store Connect API**（任意だが推奨）: 同じく「統合」→「App Store Connect API」のチームキー（App Manager）を作って RevenueCat にアップロード → 製品を自動で取りこめます
5. **Products** → 「Import」（または ＋ New）で `gohancho_plus_monthly` と `gohancho_plus_yearly` を登録
6. **Entitlements** → ＋ → 識別子 **`plus`** → 2つの製品を Attach
7. **Offerings** → 「default」（または ＋ で識別子 `current`）に Package を2つ: `$rc_monthly` ＝ 月額、`$rc_annual` ＝ 年額。Offering を **Current** にする
8. **API keys** → 「App Store」の **Public app-specific API key**（`appl_` で始まる）をコピー

### 5-2. アプリに鍵を入れる（GitHub のページ上で）

1. https://github.com/akb69bka-tech/gohancho-/edit/main/gohancho/index.html を開く
2. ⌘F で `revenueCatApiKey: ''` を探し、`''` の中にコピーした鍵を貼る → `revenueCatApiKey: 'appl_xxxxxxxx',`
3. 右上 Commit changes… → Commit changes
4. Mac のターミナルで、変更を取りこんでアプリに反映:

```bash
cd ~/Documents/gohancho && git pull
cd ios-app && npm run sync
```

> この鍵が入ると、iPhone アプリ版だけ課金が有効になります（Web 版は無料のまま）。鍵は「公開用」なのでアプリに入れて問題ありません。

## 6. iPhone でテスト購入（Sandbox）

Sandbox は「お金のかからない練習用の App Store」です。

1. App Store Connect → **「ユーザとアクセス」→「Sandbox」→「テスター」** → ＋ で、ふだん使っていないメールアドレスでテスト用 Apple ID を作る（実在しなくてよい形式のメールも可。パスワードはメモ）
2. iPhone の **設定 → App Store** → 一番下の「サンドボックスアカウント」にそのアカウントでサインイン
3. Xcode で ▶ を押してアプリを入れ直す（鍵入りの最新版）

## 付録C: 用語

| 用語 | 意味 |
| --- | --- |
| Apple Developer Program | アプリを App Store に出すための有料会員（年99米ドル） |
| App Store Connect | App Store に出す情報・課金・売上を管理する Apple のサイト |
| Xcode | Apple 製の開発ソフト。iPhone アプリを組み立てて Apple に送るのに使う |
| バンドル ID | アプリの世界で唯一の名前（`io.github.akb69bka.gohancho`）。一度出すと変えられない |
| ビルド | 組み立てたアプリ1個のこと。番号 `1.1.0 (1)` の `(1)` がビルド番号 |
| Archive / アップロード | 組み立てて Apple のサーバーに送ること |
| TestFlight | 送ったビルドを、公開前に自分や知人の iPhone で試せるしくみ |
| Sandbox | お金のかからないテスト用の購入環境 |
| RevenueCat | 購入が有効かを確かめる外部サービス。アプリの課金の裏方 |

| Entitlement | RevenueCat での「有料会員の権利」の名前（このアプリでは `plus`） |

## 付録D: Mac を使わない方法（GitHub Actions で組み立てて送る）

Mac が無い場合、GitHub のサーバー上の Mac で組み立てて Apple に送れます。「1」「2」「4」「5-1」はこの方法でも必要です（「3」「6」「7-1」の代わり）。

1. App Store Connect →「ユーザとアクセス」→「統合」→「App Store Connect API」→ チームキー ＋（名前 `github-actions`、アクセス **App Manager**。「クラウド管理による配布証明書へのアクセス」のような項目があればオン）→ .p8 をダウンロード、Issuer ID・キー ID をメモ
2. Team ID: https://developer.apple.com/account → メンバーシップの詳細
3. https://github.com/akb69bka-tech/gohancho-/settings/secrets/actions → **New repository secret** で6つ登録: `APPLE_TEAM_ID`、`ASC_KEY_ID`、`ASC_ISSUER_ID`、`ASC_API_KEY_P8`（.p8 をテキストで開いた中身）、`REVENUECAT_API_KEY`（appl_…）、`SUPPORT_EMAIL`
4. https://github.com/akb69bka-tech/gohancho-/actions/workflows/ios-release.yml → **Run workflow** → version `1.1.0` → Run。15〜25分で App Store Connect にビルドが届きます（赤くなったら、そのページの URL を Claude に貼ってください）
5. テスト購入は TestFlight で: App Store Connect の TestFlight にビルドが届いたら、自分を内部テスターに追加 → iPhone に TestFlight アプリを入れて開く → 「6」の手順で Sandbox 購入
6. あとは「7-2」「7-3」と同じ

注意: 非公開リポジトリでは GitHub Actions の macOS の無料枠（月およそ200分）を超えると有料です。公開リポジトリなら無料（出典: https://docs.github.com/ja/billing/managing-billing-for-github-actions/about-billing-for-github-actions ）。
